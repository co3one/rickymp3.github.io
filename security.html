Security

Who is responsible for security at CO3 ONE, and how to report a vulnerability.

Security Lead

Ricardo Cruz Orozco, Founder & CEO, leads security for CO3 ONE and its products, including SENTINEL and miji.

Security for all products is managed by CO3 ONE LLC, the operating entity.

Report a Vulnerability

If you believe you've found a security issue in a CO3 ONE product or on co3.one, email founder@co3.one.

Include a description of the issue and the steps to reproduce it.
Test only against accounts and data you own.
Give us reasonable time to fix the issue before disclosing it publicly.
